# AI DevOps Log Analyzer

AI-powered DevOps troubleshooting dashboard built using Python and Streamlit.

## Features
- Upload and analyze log files
- Detect ERROR, WARN, FAILED, and Exception logs
- Severity dashboard charts
- AI-assisted root cause analysis

## Tech Stack
- Python
- Streamlit
- Pandas
- Git
- GitHub

## Future Improvements
- OpenAI integration
- Kubernetes log analysis
- Docker troubleshooting
- Jenkins pipeline analysis
